# PetroCalc-Ai

Petroleum engineering calculation and AI assistant application.

## Overview
- **Stack:** Python (anticipated) / Web Calculator
- **Purpose:** Perform petroleum engineering calculations with AI-assisted insights.

## Development & Verification
- **Setup:** Create a virtual environment and install dependencies as they are added to `requirements.txt` or `pyproject.toml`.
- **Testing:** Run pytest once tests are established.
